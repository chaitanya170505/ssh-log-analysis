# 🔐 SSH Log Analysis Using Splunk

## 📌 Project Overview
This project focuses on analyzing SSH authentication logs to detect suspicious activities such as brute-force attacks, repeated failed login attempts, and unauthorized access patterns.

The analysis is performed using the SIEM platform **Splunk**, which helps in visualizing logs, identifying attack patterns, and generating security insights.

---

- Detect SSH brute-force attacks
- Identify repeated failed login attempts
- Track suspicious IP addresses
- Analyze authentication trends over time
- Improve understanding of attacker behavior using logs
